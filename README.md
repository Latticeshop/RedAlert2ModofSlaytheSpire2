# 红警2 Mod - Slay the Spire 2

将《红色警戒2》的经典元素带入《杀戮尖塔2》！选择盟军或苏联阵营，体验独特的经济系统、科技树和单位生产机制。

## 🎮 游戏特色

### 双阵营选择
- **盟军**：高科技单位，精准打击
- **苏联**：重型装甲，强力压制

### 独特的经济系统
- 黄金矿、宝石矿、油井提供持续收入
- 出售基地车获取紧急资金
- 经济卡池管理

### 生产序列系统
- 兵营、重工、船厂生产不同类型单位
- 科技建筑解锁高级单位
- 部署机制存储单位

### 绝地战备
- 飞鹰系列空袭支援
- 毁灭性的超级武器

## 📦 安装要求

- 《杀戮尖塔2》游戏本体
- RitsuLib 模组（Steam创意工坊）

## ⚡ 快速上手

1. 选择阵营开始游戏
2. 建造建筑获取资源和生产单位
3. 升级科技解锁高级单位
4. 使用超级武器终结敌人
